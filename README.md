# Мій улюблений фільм: Крик 6

Сайт створено в межах практичної роботи з HTML та CSS.

## Структура проєкту

- index.html — головна сторінка з інформацією про фільм, розкладом сеансів, галереєю та контактами
- style.css — таблиця стилів для оформлення сторінки (темна тематика, сітки, анімації)
- images/ — папка з зображеннями (логотип, постер та кадри з фільму)

## Технології

- HTML5
- CSS3 (Flexbox, Grid)
